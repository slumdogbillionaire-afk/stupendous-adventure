# 🧞 Stupendous Adventures of Astonishing Heroes

A genie-cursed superhero card game. Every hero asked a genie for a power — and got the equal-and-opposite curse they didn't ask for.

## 🎮 Play Now

Open `index.html` in any browser. No server needed. Works on desktop and mobile.

## ✨ Features

- **50 genie-cursed heroes** with paired opposite superpowers
- **10 champion heroes** with unique abilities and cooldowns (1-4 battles)
- **10 action cards** — steal, banish, swap, heal, damage, revive, draw 3, recover from discard, shield, chaos
- **Draft system** — draw 7, keep 5 at game start
- **d20 combat** with ATK/ARM/HP/SPD, crits, fumbles, overkill damage
- **Player HP (100)** with overkill spillover and revive system
- **Genie's Twist** — 15 random events fire every 4 turns
- **Pass-the-phone** multiplayer for 2-6 players
- **Sound effects** — 14 procedural Web Audio sounds, zero external assets
- **Win/loss tracking** with persistent leaderboard
- **End-of-game replay** timeline
- **Victory confetti** 🎊
- **Pre-battle win probability** bar
- **Card flip animation** on draw

## 🏗 Tech

Single self-contained HTML file (~143KB). No build step, no dependencies, no server.
